# EP20 不死者 - 任務流程與操作說明

## 📋 專案概述

本專案為《Ragnarok Online》EP20主線任務的互動式攻略網頁，提供完整的任務流程指引、材料需求清單、NPC對話座標，以及獎勵資訊。

---

## 🎯 核心功能

### 1. 任務材料需求清單
- 圖示化顯示所有所需材料
- 標示數量、取得方式與用途
- 可折疊/展開顯示

### 2. 互動式任務追蹤
- 逐步勾選完成的任務步驟
- 進度自動保存
- 獎勵顯示

### 3. 快速導航功能
- 一鍵複製NPC對話座標
- 提供 `/navi` 指令直接導航
- 響應式設計，支援行動裝置

### 4. 獎勵追蹤
- 每個任務步驟完成後顯示獎勵
- 總獎勵統計

## 🛠️ 使用說明

### 基本操作
1. **勾選任務步驟**：
   - 點擊每個任務步驟前的方塊
   - 已完成的步驟會自動保存進度

2. **複製座標**：
   - 點擊「與NPC對話」按鈕
   - 自動複製 `/navi` 座標到剪貼簿
   - 在遊戲中粘貼使用

3. **重置進度**：
   - 點擊頁面底部的「PURGE // RESET ALL PROGRESS」按鈕
   - 清除所有勾選狀態

### 快速鍵
- **回到頂部**：頁面滾動後右下角會出現按鈕
- **材料清單**：點擊頁面頂部的「[DATA_CORE] 任務材料需求」標題

## ⚠️ 注意事項

1. **變身狀態**：
   - 進入蛇城區域前必須使用蠕蟲變身卷軸變身
   - 部分任務需要保持變身狀態才能完成

2. **前置任務**：
   - 確保已完成「埋蛤蜊任務」才能接取相關任務

3. **團隊配合**：
   - 部分多人副本需要團隊配合
   - 建議提前組隊

4. **遊戲更新**：
   - 本攻略可能因遊戲更新而有所變動
   - 以遊戲內實際內容為準
