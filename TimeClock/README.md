# Da Ka - 打卡

一款極致輕量、雙模式時間打卡網頁工具。支援離線使用與 Firebase Realtime Database 實時同步，採用 **Coding Agent / IDE Terminal** 開發者極客風格設計。點擊即可按類別記錄時間，勾選項目自動計算總時長，所有資料儲存在瀏覽器本地與雲端。

---

## 💡 功能特色

### 核心功能
- **一鍵分類打卡** — 支援「🚆 通勤」、「🛠 工作」、「🛒 購物」三種打卡類型，點擊即刻精確紀錄時間（`YYYY/M/D H:MM:SS AM/PM`）。
- **勾選區間計時** — 勾選任意兩筆以上時間，自動計算最早至最晚的總時長（X 小時 Y 分 Z 秒），並同步統計各類型分項時數。
- **即時時間與數據儀表板** — 頂部與摘要面板即時顯示秒級更新時間、總記錄數、已選筆數與最新同步狀態。
- **備註功能** — 支援為每筆記錄動態新增與修改備註說明。
- **多元匯出** — 支援匯出為 **CSV** (含 UTF-8 BOM，適用 Excel)、**TXT** 及 **MD (Markdown)** 格式。
- **一鍵備份與清除** — 支援清空所有歷史記錄（附帶安全確認提示）。
- **全裝置響應式支援 (RWD)** — 完美自適應手機、平板與桌機螢幕排版，手機端自動切換為觸控友善的滿版按鈕。

### 雲端與本機同步
- **多裝置實時同步** — 基於 Firebase Realtime Database 實現多端資料自動串聯。
- **離線快取優先** — 採用 `localStorage` 本機快取機制，無網路時亦可完全正常瀏覽與打卡。
- **狀態即時監控** — 頂部與側邊欄面板實時顯示同步狀態 (`SYNCING` / `OFFLINE`)。

## 🚀 快速開始

1. 下載或開啟 `index.html`。
2. 直接用任何現代瀏覽器開啟即可開始打卡。
3. 預設即啟動本機儲存與 Firebase 實時同步。

---

## 🛠 使用說明與快捷操作

| 操作 | 說明 |
|------|------|
| 點擊「🚆 通勤」 | 新增一條通勤時間記錄 |
| 點擊「🛠 工作」 | 新增一條工作時間記錄 |
| 點擊「🛒 購物」 | 新增一條購物時間記錄 |
| 勾選記錄前方的 ☐ | 選取要計算區間的時間項目（兩筆以上自動計算） |
| 在備註欄位輸入 | 為該筆記錄添加說明 |
| 點擊「匯出 ▼」 | 可選 CSV / TXT / MD 下載打卡資料 |
| 點擊「清除全部」 | 清空本機與雲端所有記錄（需確認） |

## 📄 匯出格式說明

### 1. CSV (`.csv`)
- 帶 UTF-8 BOM 標頭，微軟 Excel 開啟不亂碼。
- 包含：序號 (No.)、時間 (DateTime)、勾選狀態 (Checked)、類型 (Type)、備註 (Note) 以及底部總計區間。

### 2. TXT (`.txt`)
- 純文字清單格式，便於快速複製剪貼。
- 底部附通勤、工作與購物之總時數統計。

### 3. Markdown (`.md`)
- 標準 Markdown 表格格式，適合直接插入 Notion、GitHub README 或 Obsidian。

## 📝 技術架構

- **純前端單頁應用 (SPA)**：單一 `index.html`，無需任何 Node.js 建置步驟。
- **儲存機制**：`localStorage` + Firebase Realtime Database (Compat SDK v10.12.2)。
- **字體依賴**：Google Fonts (`JetBrains Mono`, `Fira Code`, `Inter`)。
